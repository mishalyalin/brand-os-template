# Evidence

Owner: {{ YOUR_NAME }}.

Append-only folder for primary-source evidence backing brand claims, competitor patterns, and regulatory references.

Each file is date-stamped: `YYYY-MM-DD-<slug>.md`.

Subfolders organize by topic (suggested):
- `competitor-teardowns/` - decoded patterns from category competitors and reference brands
- `regulatory/` - regulator letters, classification rulings, lab reports
- `customer-research/` - survey data, interview transcripts, support-ticket patterns
- `studies/` - academic studies cited in cocktails

**Append-only rule:** never edit or delete an evidence file. If a finding is superseded, add a new file referencing the old one.

Claims that cannot trace to a file in this folder, a Brain Vault row, or an `[INFERRED]` tag fail the Claims Trace CI check.
